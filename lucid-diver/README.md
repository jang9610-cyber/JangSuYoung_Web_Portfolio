# 침몽도시: 루시드 다이버 포트폴리오 웹

현재 버전은 향후 유리 파편 인터랙션으로 분해하기 전의 **통합 기억 기준본**이다.
면접관이 별도 조작 없이도 프로젝트 전체를 읽을 수 있도록 모든 핵심 정보를 한 페이지에 배치했다.

## 구조

- `index.html`: 실제 포트폴리오 본문. 큰 단위마다 `data-fragment-id`를 가진다.
- `js/content.js`: 파편 순서, 목차, 플레이 루프 데이터를 관리하는 manifest.
- `js/app.js`: 목차, 범위 필터, 플레이 루프 탭, 라이트박스 등 공통 기능.
- `css/style.css`: 통합본과 향후 파편 화면이 공유할 시각 체계.
- `assets/images`: 기존 최종 발표 웹에서 선별해 복사한 웹 전용 증거 이미지.

## 파편화 예정 단위

1. 프로젝트 요약
2. 장르 문제
3. 이중 보상 루프
4. P0 결정
5. 플레이 흐름
6. 개인 기여
7. 기획에서 런타임
8. 구현 및 QA
9. 팀과 증거
10. 최종 자료

## 교체 예정 미디어

- 배경용 공식 PV: 무음·자동 재생·반복 가능한 WebM 또는 MP4
- 최종 발표 녹화 영상: `RESTORED ARCHIVE`의 대기 카드에 연결
- 필요 시 최종 회고 및 QA 수치: 현재 날짜가 명시된 알파 교차검증 수치와 구분해 갱신

필수 정보는 파편 인터랙션을 거치지 않아도 항상 접근 가능하게 유지한다.
