# 침몽도시: 루시드 다이버 포트폴리오 웹

현재 버전은 향후 유리 파편 인터랙션으로 분해하기 전의 **면접관용 요약 기준본**이다.
모든 기억 파편이 이미 결합된 하나의 유리 기록판을 콘셉트로, 별도의 내부 스크롤 없이 브라우저 스크롤 하나만으로 개인 역할·핵심 성과·영상·기획서·세계관·에셋·발표·최종 결과를 확인하도록 구성했다.

## 구조

- `index.html`: 실제 포트폴리오 본문. 큰 단위마다 `data-fragment-id`를 가진다.
- `js/content.js`: 파편 순서, 목차, 플레이 루프 데이터를 관리하는 manifest.
- `js/app.js`: 목차, 범위 필터, 플레이 루프 탭, 라이트박스, 선택형 SSOT 원문 뷰어 등 공통 기능.
- `css/style.css`: 침몽도시의 청록·보라 계열 유리 기록판과 반응형 요약 레이아웃.
- `assets/images`: 기존 최종 발표 웹에서 선별해 복사한 웹 전용 증거 이미지.

## 파편화 기준 단위

1. 나는 누구인가
2. 핵심 성과
3. 시연 및 증거 영상
4. 핵심 기획서
5. 세계관 요약
6. 이미지 에셋
7. 최종 발표 자료
8. 빌드 및 GitHub

## 교체 예정 미디어

- 배경용 공식 PV: 무음·자동 재생·반복 가능한 WebM 또는 MP4
- 최종 발표 녹화 영상: `RESTORED ARCHIVE`의 대기 카드에 연결
- 필요 시 최종 회고 및 QA 수치: 현재 날짜가 명시된 알파 교차검증 수치와 구분해 갱신

필수 정보는 파편 인터랙션을 거치지 않아도 항상 접근 가능하게 유지한다.
상세 설계·플레이 루프·QA는 본문에서 제외하고 발표 자료와 SSOT 원문 안에서만 선택 열람한다.
SSOT 원문은 사용자가 요청할 때만 문서 탐색기를 지연 로딩한다.
